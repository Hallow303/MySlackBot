# My First Slack Bot

This bot isn't slacking off — it replies to commands 24/7!

## Commands

| Command      | Description                                                   |
| ------------ | ------------------------------------------------------------- |
| `/koi-ping`  | Replies with `Pong!`.                                         |
| `/koi-apod`  | Shows NASA's Astronomy Picture of the Day.                    |
| `/koi-cat`   | Displays a random cat image.                                  |
| `/koi-dog`   | Displays a random dog image.                                  |
| `/koi-fox`   | Displays a random fox image.                                  |
| `/koi-duck`  | Displays a random duck image.                                 |
| `/koi-say`   | Repeats the text you send.                                    |
| `/koi-sound` | Lets you choose an animal and plays its sound.                |
| `/koi-tts`   | Converts your text into speech and sends it as an MP3 file.   |
